A Simple PDF Editor: 
Split pages, Merge, Rearrange, add Signature, Image and Text 

— Cross-platform — Support multi-language fonts — Offline — With Privacy

Fully client side code, can be packaged in any modern webview/browser/electron/wails,
Works on iOS, Andriod, Windows, MacOS, Linux, etc once packaged/host the "dist" folder properly.
